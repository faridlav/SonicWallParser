# Work log: analyzer v2

Chronological record of what was done on `feature/analyzer-v2`, for human and agent review.
Rules for this file: no data derived from real samples (no counts, names, IPs or serials from them),
no secrets, no em dashes. Real-sample verification results are reported in chat, not here.

Conventions: each entry lists the commit, what changed, why, how it was verified, and anything
left unverified. "Probe" means a throwaway console project kept outside the repo that printed key
names (and low-cardinality enumeration values only) from local samples.

## Environment

- Only SDK 11.0.100 is installed. It builds and tests net10.0 correctly, so no `global.json` was added.
- `samples/` is git-ignored. It holds four `.exp` files (the brief named three). Only the three named were used.
- Baseline before any change: 7 tests passing, CLI run on three samples, section counts recorded locally.
